01 / REOLINK

Wo klingelt es?

Verbinde die Kamera direkt oder über deinen Reolink-NVR.

Klingelereignisse

Der direkte Trigger nutzt den ausgewählten Kamerakanal. Nach einer Wiederverbindung wird der erste Zustand als Ausgangszustand übernommen.

02 / TELEFONIE

Wer soll erreichbar sein?

„auto“ verwendet den Router als SIP-Telefonanlage. Eine eigene Adresse ist jederzeit möglich.

Zusätzliches Konto für Mobilrufe

03 / ANRUFROUTEN

Wen ruft die Klingel an?

Jede Route kann eine FRITZ!Box-Klingeltaste und bis zu drei Mobilrufnummern verwenden. Der direkte Reolink-Trigger startet eine ausgewählte Route.
